# Rule: Documentation & README Style Guidelines

1. **No AI-Slop & No Emojis**:
   - Keep README.md and documentation strictly professional, technical, and concise.
   - Never use emojis, decorative icons, marketing fluff, or AI-slop phrases (e.g., "Supercharge your gameplay!", "Delve into the realm!").

2. **Complete Feature Coverage**:
   - Ensure all implemented project features (e.g., Sale Star drop multipliers, Shrine win rates, ESP filters, Economy steppers) are documented in README.md.
   - Remove references to deleted tabs, obsolete features, or removed UI elements immediately.
